### Tabla: Campos de Result (Recibos de Pago)

| Campo               | Nombre en Español       | Tipo        | Descripción                                               |
| ------------------- | ----------------------- | ----------- | --------------------------------------------------------- |
| API_ESTADO          | Estado API              | string      | Estado de la transacción (ej. "PAGADO")                   |
| API_TRANSACCION     | Tipo de Transacción API | string      | Acción realizada (ej. "PAGAR")                            |
| DESC_IDENTIFICACION | Identificación          | string      | RTN o identidad del pagador                               |
| DESC_INSTITUCION    | Institución             | string      | Nombre completo de la institución receptora               |
| FEC_CRE             | Fecha de Creación       | datetime    | Fecha y hora en que se creó el registro                   |
| FEC_MOD             | Fecha de Modificación   | datetime    | Fecha y hora de la última modificación                    |
| INSTITUCION         | Código de Institución   | string      | Código identificador de la institución                    |
| LST_RUBROS          | Lista de Rubros         | array       | Detalle de rubros/conceptos pagados (ver tabla siguiente) |
| MONTO               | Monto                   | decimal     | Monto total pagado en el recibo                           |
| NOMBRE_RAZON        | Nombre / Razón Social   | string      | Nombre del pagador o empresa                              |
| NRO_RECIBO          | No. De Recibo           | decimal     | Número único del recibo de pago                           |
| SIGLA_INSTITUCION   | Sigla de Institución    | string/null | Acrónimo de la institución                                |
| TIPO_IDENTIFICACION | Tipo de Identificación  | string      | Tipo de documento (ej. "ID", "RTN")                       |
| USU_CRE             | Usuario Creador         | string      | Usuario que creó el registro                              |
| USU_MOD             | Usuario Modificador     | string      | Usuario que realizó la última modificación                |

### Tabla: Campos de LST_RUBROS (Rubros del Recibo)

| Campo                    | Nombre en Español  | Tipo    | Descripción                                                   |
| ------------------------ | ------------------ | ------- | ------------------------------------------------------------- |
| RUBRO                    | Código de Rubro    | string  | Código numérico del rubro/concepto                            |
| DESCRIPCION              | Descripción        | string  | Código y nombre descriptivo del rubro                         |
| MONTO                    | Monto              | decimal | Monto asociado a este rubro específico                        |
| LST_INST_RUBROS_ARTICULO | Lista de Artículos | array   | Detalle de artículos asociados al rubro (ver tabla siguiente) |

### Tabla: Campos de LST_INST_RUBROS_ARTICULO (Artículos del Rubro)

| Campo       | Nombre en Español  | Tipo    | Descripción                               |
| ----------- | ------------------ | ------- | ----------------------------------------- |
| ARTICULO    | Código de Artículo | string  | Código numérico del artículo              |
| DESCRIPCION | Descripción        | string  | Código y nombre descriptivo del artículo  |
| MONTO       | Monto              | decimal | Monto asociado a este artículo específico |
