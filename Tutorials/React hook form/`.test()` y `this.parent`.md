
Cuando necesitas validar un campo basándote en el valor de **otros campos** del formulario, la combinación de `.test()` y `this.parent` es la herramienta definitiva en Yup.

---

### 1. ¿Qué es `.test()`?
Es un **guardián personalizado**. Te permite escribir una función de JavaScript con tu propia lógica de negocio.
* **Si la función retorna `true`:** El campo es válido.
* **Si la función retorna `false`:** La validación falla y se dispara tu mensaje de error.

### 2. ¿Qué es `this.parent`?
Es un objeto que contiene **los valores actuales de todos los hermanos (los otros inputs)** del formulario en tiempo real. 

> ⚠️ **REGLA DE ORO:** Para usar `this.parent`, la función dentro del `.test()` **DEBE** ser una función clásica de JavaScript (`function() {}`). **No uses Arrow Functions (`() => {}`)**, ya que las arrow functions pierden el acceso al contexto `this` de Yup.

---

### Ejemplo Práctico: Al menos uno debe ser requerido

Queremos que el usuario marque obligatoriamente `sendEmail` **O** `sendSms`. Al menos uno debe ser `true`.

```typescript
import * as yup from "yup";

export const miEsquema = yup.object().shape({
  sendEmail: yup.boolean(),

  sendSms: yup.boolean().test(
    "nombre-del-test", // 1. Identificador único para el test
    "Debes seleccionar al menos un método de envío", // 2. Mensaje de error si retorna false
    function (value) { // 3. Función clásica (NO usar =>)
      // 'value' es el estado actual de 'sendSms'
      // 'this.parent' nos permite espiar el estado de 'sendEmail'
      const { sendEmail } = this.parent;

      // Condición: Es válido si este es true O si el correo es true
      return value === true || sendEmail === true;
    }
  ),
}, [
  ["sendEmail", "sendSms"] // Matriz de dependencia para evitar bucles infinitos
]);
