
| **Acción**                            | **Comando npm**                                                                          | **Comando pnpm**                                                                       | **Comando Bun**                              |
| ------------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------- |
| **Instalar todo**                     | `npm install`                                                                            | `pnpm i`                                                                               | `bun install` (o `bun i`)                    |
| **Añadir paquete**                    | `npm install <pkg>`                                                                      | `pnpm add <pkg>`                                                                       | `bun add <pkg>`                              |
| **Añadir a devDependencies**          | `npm install <pkg> -D`                                                                   | `pnpm add -D <pkg>`                                                                    | `bun add -D <pkg>`                           |
| **Eliminar paquete**                  | `npm uninstall <pkg>`                                                                    | `pnpm remove <pkg>`                                                                    | `bun remove <pkg>`                           |
| **Ejecutar scripts**                  | `npm run <script>`                                                                       | `pnpm <script>` (o `pnpm run`)                                                         | `bun run <script>` (o `bun <script>`)        |
| **Aprovar ejecución**                 | `npm install` _(Ver nota)_                                                               | `pnpm approve-builds`                                                                  | _(No aplica por defecto)_                    |
| **Correr a prod**                     | `npm run build`                                                                          | `pnpm build`                                                                           | `bun run build` (o `bun build`)              |
| **Preview**                           | `npm run preview`                                                                        | `pnpm preview`                                                                         | `bun run preview`                            |
| **Package lock json**                 | _(No aplica)_                                                                            | `pnpm import`                                                                          | `bun install` _(Genera `bun.lock`)_          |
| **Para actualizar**                   | `npm outdated`<br><br>  <br><br>`npm update`<br><br>  <br><br>`npx npm-check-updates -u` | `pnpm outdated`<br><br>  <br><br>`pnpm update`<br><br>  <br><br>`pnpm update --latest` | `bun outdated`<br><br>  <br><br>`bun update` |
| **Limpiar cache**                     | `npm cache clean --force`                                                                | `pnpm store prune`                                                                     | `bun pm cache rm`                            |
| **Elegir qué actualizar visualmente** | `npx npm-check-updates -i`                                                               | `pnpm update --interactive`                                                            | _(No nativo / Usa `npx ncu -i`)_             |
